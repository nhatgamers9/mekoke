# Slider

Thanh kéo mức 0–1 dựng trên `<input type="range">` thật: âm lượng từng âm trong bản phối, âm lượng chung.

- Truyền `value`, `onChange`, `title` (hiện kèm phần trăm) hoặc `label` (chỉ cho trình đọc màn hình) và tuỳ chọn `icon`.
- Phần đã kéo màu `amber`, phần còn lại `surface-2`, núm `ink` có viền `surface`.
- Trong Flutter: `Slider` với `activeColor` amber, `inactiveColor` surface-2, `thumbColor` ink.
