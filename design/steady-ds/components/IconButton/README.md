# IconButton

Nút tròn chỉ có icon; bắt buộc truyền `label` để trình đọc màn hình đọc được.

- `play` (72px, nền amber): nút Play/Pause chính của Focus, Timer và hẹn giờ ngủ. Mỗi màn hình một nút.
- `filled` (48px, nền `surface-2`): điều khiển phụ cạnh nút Play (Restart, Skip round).
- `plain` (48px, trong suốt, icon `ink-muted`): góc trên của màn hình (Settings, Close).
